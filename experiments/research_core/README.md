# Gated Core Experiments

**Status:** Reserved; no core experiment is implemented

Future experiment groups will follow the scientific gates rather than method
brands:

```text
01_conflict_identifiability/
02_representation_comparison/
03_calibration_incremental_validity/
04_selective_review/
```

Do not create these directories merely to suggest progress. A directory is
added only when a frozen `TASK_BRIEF` names its prediction unit, data version,
intervention manifest, primary endpoint, baselines, configuration schema,
promotion criteria, and stopping rule.

Every published table or figure must be reproducible from one documented
command and a versioned configuration.
